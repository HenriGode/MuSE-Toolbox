# Experiments
**The "Muscles" of the Framework**

## Purpose
This directory contains the execution scripts (Bash/Shell). Neither logic nor config lives here—only the commands to launch jobs on an HPC or local machine.

## Vertical Structure
1.  **Topic** 
2.  **Subtopic** 
3.  **Experiment Script** (`run_job.sh`)

## Usage
These files define **HOW** to run.
Example: `bash experiments/topic/subtopic/run_job.sh`

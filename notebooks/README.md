# Notebooks
**Exploration and Analysis**

## Purpose
Jupyter notebooks for interactive coding, debugging, and figure generation.

## Structure
- **playground/**: Throwaway code for quick tests.
- **data_statistics/**: Analysis of dataset distributions.
- **causality/**: Checks for causality in signal processing chains.
- **visualization/**: Polish code to generate high-quality figures for papers.
- **profiling/**: Code speed and memory optimization.
